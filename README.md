# NavaStream

Automated music discovery and publishing platform.

## Core Features

- Discover new music releases from configured sources
- Extract track metadata and official source URLs
- Search accessible Telegram sources for matching tracks
- Verify redistribution permissions before audio publishing
- Maintain a persistent publishing queue
- Resume processing after internet interruptions
- Publish authorized tracks to the target Telegram channel

## Project Structure

- app/: Application source code
- data/: Local database and persistent state
- logs/: Application logs
